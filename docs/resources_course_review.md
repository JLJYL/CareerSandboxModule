# 課程技能抽取 — 人工覆核清單（成員 A／B）

## 這份怎麼來的
- 來源：全國課程檔 `courses_dedup.jsonl`（138,543 筆）→ 篩「中山」→ 去重 → **334 門**課。
- 方法：**字面抽取**（`build_resources.py extract --literal`）——掃**課名**，命中詞彙表表面形就當技能。
  沒有 LLM 金鑰，所以沒讀大綱；課名訊號強，但 recall／precision 都不如 LLM 讀大綱。
- 已內建的防誤判：排除 `AI`／`ML`／`TS` 等 ASCII≤2 別名（否則任何帶 AI 字樣的課都被塞成機器學習）。
- 規模：352 筆「課—技能」對，涵蓋 29 項技能。

## 要你做的事
掃過各組，把**明顯不該歸在此技能**的課名挑出來，從 `fixtures/resources/resources_v1.json` 移除該課的對應技能（或整筆）。常見誤判：
- 「統計力學／熱統計物理／統計熱力學」是**物理**，不是統計分析。
- 「癌症治療策略／纖維化治療策略」是**醫學研究**，不是策略規劃。
- 語言課「日文溝通／法文溝通」歸在溝通協調，看你們要不要留。

## 已知限制（拿到 LLM 金鑰可解）
- **recall 漏接**：課名沒寫出技能的會漏。例：UX 相關課多叫「人機互動」，詞彙表標準名是「使用者體驗設計」，字面對不上 → 這類技能目前只配得到競賽。
- 升級法（設好 `.env` 金鑰後，讓 LLM 讀大綱抽技能）：

```bash
python tools/build_resources.py extract \
    --courses data/courses_dedup.jsonl --school nsysu --school-match 中山 \
    --provider 國立中山大學 --out data/resources_raw_skills.jsonl
python tools/build_resources.py build \
    --raw data/resources_raw_skills.jsonl --competitions data/competitions_manual.csv \
    --out fixtures/resources/resources_v1.json \
    --residuals docs/resources_residuals_report.md --real
```

目前這份是用 `--literal`（免金鑰）產的；上面指令拿掉 `--literal` 即走 LLM 路徑。
