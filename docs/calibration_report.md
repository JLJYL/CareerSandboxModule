# §4 語意對映與權重校準報告

> 承 2026-10-22 交接「計分器要改的四個地方」§4：用黃金集重看語意對映與 0.65 / 0.35 權重，

## 三、定案

**(1) 語意對映：原始餘弦 → 線性對映 `f(c) = clamp((c − 0.35) / (0.60 − 0.35), 0, 1)`。**
錨點取自上面兩帶：0.35 ＝ 離題地板（離題平均 0.353、真實低端叢集），0.60 ＝ 滿分天花板（滿分平均 0.567，略高於它，要求近滿分才給到 1.0）。效果：離題文本被壓回 0 附近、滿分對才接近 1，中間真實配對攤開到 0–0.83，除掉原始餘弦的 ~35 虛高地板。

為什麼不把地板訂更高（例如 0.47）好把離題全壓成 0：那會連半數真實配對一起壓成 0——三帶重疊、沒有乾淨切點（與課程技能抽取遇到的「對錯餘弦重疊、無乾淨門檻」是同一個現象）。線性對映只能攤開、不能無中生有把重疊的帶分開；這是 bge-m3 短中文文本的物理極限，不是參數救得回的。

**(2) semantic_only 壓分：改為「先線性對映、再保留 `w_cover` 上限」**，即 `round(100 · f(c) · w_cover)`，取代原本的 `round(100 · c · w_cover)`。
B 問「暫定壓分要不要換成線性對映」——答案是**對映要換上**（除虛高地板），但 **`w_cover` 上限要留**，因為兩者解的是不同問題：對映除地板；上限反映「這份工作零技能證據、只靠近乎雜訊的語意」本就不該衝到滿分。七成真實 jobs 無 `required_skills` 走這條路，換上後這批從原本壓在 **21–36** 的窄帶（離題與適配混在一起）攤成 **0–54**，離題趨 0、較相關者才拿得到中段分。

**(3) 權重 0.65 / 0.35：維持不動。**
黃金集只有 15 點、且語意與覆蓋率負相關，拿它重擬權重等於對雜訊過擬合。真要動，負相關指向的是「語意該更低」而非更高，但 15 點不足以定案。因此維持 0.65 / 0.35，把真正的修正放在對映上；待日後有 (a) 更豐富的經歷敘述、或 (b) 帶「分數標籤」的黃金集，再回頭重估權重。覆蓋率仍是主腿，與黃金集「只裁覆蓋、不裁分數」的定位一致。
